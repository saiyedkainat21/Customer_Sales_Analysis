# Customer Sales Analysis

## Project Overview
This project analyzes customer sales data to identify sales trends, customer purchasing patterns, and top-performing locations using Excel, SQL, and Power BI.

## Tools Used
- Microsoft Excel
- SQL
- Power BI

## Project Objectives
- Analyze sales performance and monthly trends.
- Understand customer purchasing patterns.
- Identify top-performing locations.
- Create a dashboard to communicate business insights.

## Key Insights
- July recorded the highest sales.
- Female customers represented the most active customer group.
- Mall of Istanbul was the highest-performing location.

## Project Files
| File | Description |
| Customer Data Analysis Project.xlsx | Excel workbook used for sales analysis |
| Customer_Sales_Analysis.sql | SQL queries used to analyze the data |
| Final dashboard.pbix | Power BI dashboard for visualizing sales insights |

## Conclusion
This project demonstrates the use of Excel, SQL, and Power BI to analyze sales data, identify trends, and generate actionable business insights.
